AUDIO FOLDER
Create a folder named "audio" next to index.html and put these files in it:

  audio/Music.mp3    recovery music for the Music group (10 min or shorter, it loops)
  audio/nature.mp3   30-second natural sound for the Quiet group (played 2 times at random moments)

Names and paths can be changed in config.js (music.audioFile and natureCues.files).
Delete this file if you like.
